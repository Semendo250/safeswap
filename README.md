# SafeSwap

Campus marketplace for Maseno University students, with identity and
device-verification safety features built in.

## Structure

- `backend/` - Node/Express + MongoDB API
- `frontend/` - React (Vite) web app
- `docs/` - architecture notes and evaluation metrics for the project report

## Status

- Phase 1 (auth foundation): backend implemented and working
- Phase 2-4: folders and placeholder files scaffolded, logic not yet written

See `backend/README.md` for backend setup instructions.
